Chapter 01 · agent 的心脏:一个 loop

把模型想成一个很聪明、但手脚被绑住的助理:能想、能说,却读不了文件、跑不了命令。 它只能提议"帮我读 README",真去执行、把结果递回去、再问它下一步的,是屋外那个人—— agent loop。这一章你就写这个人。

一句要记住的: 模型只会「提议」,执行永远是 loop 的事。 模型说"调用 read"不代表文件被读了——真去读、把结果塞回对话、再叫模型继续的,是你写的 loop。 对任何 provider 都成立。

先别写代码。跑 npm run demo:01,把一次完整运行"看见"——尤其看清"模型提议"和"loop 执行"的区别。
